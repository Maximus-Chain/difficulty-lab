Maximus Difficulty Lab

The current Dark Gravity Wave (DGW v3) compared with LWMA-1 at several window sizes, replayed on the real chain and stress-tested with synthetic hashrate patterns. Every simulated algorithm is the same code that reproduces mainnet's own nBits.

Research only. No change to the difficulty algorithm or to emission has been decided. Any such change would be a hard fork, announced well in advance with an activation height and an upgrade window for pools, exchanges and node operators.

Method

How the numbers were produced

Headers (height, timestamp, nBits) were exported from a mainnet node with getblockheaders. A Rust port of DarkGravityWave() from src/pow.cpp recomputes every block's nBits from its predecessors and must match the chain exactly before any simulation runs.

Each simulated block draws its work from an exponential distribution and is solved against the hashrate in force at that moment. Miners lose s of work after every block to propagation and template switching. That is calibrated so that the DGW replay matches the real chain's mean, tail and burst counts.

The replay assumes miners would have behaved the same under another algorithm. Treat it as a like-for-like comparison, not a forecast. LWMA-1 follows zawy12's reference implementation, including the 6·T solvetime cap and the out-of-order timestamp handling.

Regenerate with cargo run --release -- extract then cargo run --release -- simulate.
